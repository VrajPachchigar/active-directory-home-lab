# Active Directory IT Support Ticket Simulation

This section documents common Active Directory support scenarios practiced in the lab.

## Ticket 1 — Password Reset

### User Issue

A user forgot their password.

### Resolution

The user's password was reset through Active Directory.

The account was configured so the user would be required to reset the password at the next logon.

### Skills Practiced

- User account administration
- Password reset
- Forced password change at next logon

---

## Ticket 2 — Account Locked Out

### User Issue

A user's Active Directory account was locked out.

### Resolution

The user's account was unlocked through Active Directory.

### Skills Practiced

- Account lockout troubleshooting
- User account administration

---

## Ticket 3 — Disable / Enable User Account

### User Issue

A user account needed to be disabled.

### Resolution

The user's account was disabled through Active Directory.

### Skills Practiced

- Account enable/disable operations

## Ticket 4 — Add User to HR Group

### User Issue

User `Patricia` required membership in the HR group.

### Resolution

The user `Patricia` was added to the HR group through Active Directory.

### Skills Practiced

- Group membership management
- Access administration

---

## Ticket 5 — HR Shared Folder Access

### User Issue

The HR group required access to a shared HR folder.

### Resolution

The HR folder was shared with the HR group and the folder was mapped to the Windows 11 client machine.

This allowed members of the HR group to access the required files and folders from the client machine.

### Skills Practiced

- Shared-folder access
- Group-based access
- Network folder mapping
- Windows client administration
